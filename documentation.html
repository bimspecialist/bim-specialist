Getting startedالبدء

  1. Install BIM Specialist for a supported Autodesk Revit version.
  2. Start Revit and open a project appropriate for the tool you want to use.
  3. Open the BIM Specialist ribbon and choose the required command.
  4. Review the command inputs before applying changes to the model.
  1. ثبّت BIM Specialist لإصدار Autodesk Revit مدعوم.
  2. شغّل Revit وافتح مشروعًا مناسبًا للأداة التي تريد استخدامها.
  3. افتح شريط BIM Specialist واختر الأمر المطلوب.
  4. راجع مدخلات الأمر قبل تطبيق أي تغييرات على النموذج.

Recommended: test new automation workflows on a copy of the model before using them on critical production files.يوصى بتجربة مهام الأتمتة الجديدة على نسخة من النموذج قبل استخدامها على ملفات إنتاج مهمة.

Compatibilityالتوافق

BIM Specialist is designed for Autodesk Revit 2025, 2026, and 2027. Use the build intended for your installed Revit version.تم تصميم BIM Specialist لبرنامج Autodesk Revit 2025 و2026 و2027. استخدم الإصدار المتوافق مع نسخة Revit المثبتة لديك.

Before reporting a compatibility issueقبل الإبلاغ عن مشكلة توافق

  • Confirm your exact Revit year and update level.تحقق من سنة إصدار Revit ورقم التحديث.
  • Restart Revit after installing or updating the add-in.أعد تشغيل Revit بعد تثبيت الإضافة أو تحديثها.
  • Check whether the issue occurs in more than one project.تحقق مما إذا كانت المشكلة تظهر في أكثر من مشروع.

Recommended tool workflowسير العمل الموصى به

BIM Specialist tools are intended to reduce repetitive room, schedule, and model-management steps. A safe workflow is to select the intended scope, verify inputs, run the tool, then review the resulting model or schedule before continuing.تهدف أدوات BIM Specialist إلى تقليل الخطوات المتكررة في الغرف والجداول وإدارة النموذج. سير العمل الآمن هو تحديد نطاق العمل والتحقق من المدخلات وتشغيل الأداة ثم مراجعة النتيجة قبل المتابعة.

  1. Select only the elements or views required by the command.
  2. Check names, parameters, and target schedules before execution.
  3. Run the command once and review the result.
  4. Use Undo immediately if the result is not what you expected.
  1. حدد فقط العناصر أو المشاهد التي يحتاجها الأمر.
  2. تحقق من الأسماء والبارامترات والجداول المستهدفة قبل التنفيذ.
  3. شغّل الأمر مرة واحدة ثم راجع النتيجة.
  4. استخدم Undo مباشرة إذا لم تكن النتيجة كما توقعت.

Troubleshootingاستكشاف الأخطاء

The ribbon does not appearشريط الأدوات لا يظهر

Restart Revit, confirm the add-in was installed for the correct Revit year, and verify that the installation completed without security or permission errors.أعد تشغيل Revit وتأكد من تثبيت الإضافة لسنة Revit الصحيحة ومن اكتمال التثبيت دون أخطاء أمان أو صلاحيات.

A command does nothing or reports invalid inputالأمر لا ينفذ أو يعرض مدخلات غير صالحة

Confirm that the active document, selection, view type, and required parameters match what the tool expects. Retry in a small test project if needed.تحقق من أن المستند النشط والتحديد ونوع المشهد والبارامترات المطلوبة مطابقة لما تحتاجه الأداة. جرّب في مشروع اختبار صغير عند الحاجة.
