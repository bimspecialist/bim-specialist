# BIM Specialist Website

Official bilingual product website for **BIM Specialist**, a professional Autodesk Revit productivity toolkit.

## Website

- English and Arabic interface with a persistent language selector
- Dark blue responsive product design
- Revit tools and compatibility overview
- Planned monthly and annual subscription information
- Support and privacy pages

## Product status

BIM Specialist is currently in active development and validation for Autodesk Revit 2025, 2026, and planned 2027 compatibility. It is not yet an Autodesk-approved production release.

## Files

- `index.html` — product landing page
- `support.html` — support and issue-reporting guidance
- `privacy.html` — bilingual privacy policy
- `styles.css` — shared responsive design system
- `script.js` — Arabic/English language switching
