Professional product experienceتجربة منتج أكثر احترافية

  • Improved responsive navigation and mobile behavior.
  • Added clearer product value, trial, pricing, and FAQ content.
  • Added a dedicated bilingual Documentation page and improved Support flow.
  • Added product structured data, canonical metadata, sitemap, and crawler guidance.
  • Removed public outbound GitHub destination links from the customer-facing experience.
  • تحسين التنقل وتجربة الاستخدام على الشاشات الصغيرة والجوال.
  • توضيح قيمة المنتج والفترة التجريبية والتسعير والأسئلة الشائعة.
  • إضافة صفحة مخصصة لدليل الاستخدام باللغتين وتحسين مسار الوصول إلى الدعم.
  • إضافة البيانات المنظمة وبيانات Canonical وخريطة الموقع وإرشادات محركات البحث.
  • إزالة روابط GitHub الخارجية من الصفحات العامة الموجهة للمستخدم.
